# 小程序运行配置说明

## 问题现象
运行小程序时提示：
```
Error: MiniProgramError
{"errMsg":"navigateTo:fail Error: 需要重新登录,access_token missing"}
```

## 原因分析
1. **AppID未配置**：`manifest.json` 中的 `mp-weixin.appid` 为空
2. **游客模式运行**：微信开发者工具以游客身份运行，缺少小程序身份凭证
3. **access_token 缺失**：这是微信平台的token，与我们后端API的token无关

## 解决方案

### 方案1：配置真实AppID（推荐）

1. **登录微信公众平台**
   - 访问：https://mp.weixin.qq.com/
   - 使用管理员账号登录
   - 进入"开发" → "开发管理" → "开发设置"
   - 复制 **AppID(小程序ID)**

2. **在HBuilderX中配置**
   - 打开项目根目录的 `manifest.json`
   - 找到 `mp-weixin` 节点
   - 将 `appid` 字段修改为真实的小程序AppID
   ```json
   "mp-weixin": {
       "appid": "wx1234567890abcdef",  // 替换为真实AppID
       "setting": {
           "urlCheck": false
       }
   }
   ```

3. **在微信开发者工具中配置**
   - 打开微信开发者工具
   - 点击右上角"详情"
   - 在"基本信息"中确认AppID正确
   - 如果显示"游客模式"，点击切换到真实AppID

### 方案2：使用测试号（开发测试）

如果没有正式小程序，可以申请测试号：

1. **申请测试号**
   - 访问：https://mp.weixin.qq.com/wxamp/sandbox
   - 使用微信扫码登录
   - 获取测试号AppID

2. **配置测试号**
   - 将测试号AppID填入 `manifest.json`
   - 在微信开发者工具中选择"测试号"登录

### 方案3：临时游客模式（仅用于本地测试）

如果只是临时测试，不需要微信登录功能：

1. **保持 `touristappid`**（已配置）
2. **在微信开发者工具中**
   - 点击右上角"详情"
   - 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"
   - 项目设置 → 本地设置 → 勾选"不校验请求域名、TLS版本及HTTPS证书"

3. **限制**
   - 无法使用微信登录
   - 无法获取用户信息
   - 无法真机调试
   - 无法发布上线

## 常见问题

### Q1: 提示"未找到入口app.json"
**A**: 重新编译项目，HBuilderX → 运行 → 运行到小程序模拟器

### Q2: 提示"request合法域名校验出错"
**A**: 
1. 开发者工具：详情 → 本地设置 → 不校验合法域名
2. 或在微信公众平台配置服务器域名

### Q3: 无法登录/注册
**A**: 
1. 检查后端服务是否启动（端口9090）
2. 检查nginx是否运行
3. 检查 `config.js` 中的baseUrl是否正确
4. 查看控制台网络请求是否成功

### Q4: 页面跳转报错
**A**: 
1. 确认已配置AppID（真实或测试号）
2. 检查 `pages.json` 中的页面路径是否正确
3. 确认使用 `uni.navigateTo` 而非 `uni.redirectTo`（登录页面）
